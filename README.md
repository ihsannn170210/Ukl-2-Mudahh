# Program Hitungan Ganjil Genap
Program Untuk Menentukan Angka ganjil atau Genap 
- Program meminta pengguna untuk memasukkan sebuah bilangan bulat.
- Bilangan tersebut disimpan dalam variabel number.
- Jika number % 2 != 0, maka bilangan tersebut ganjil.
- Jika tidak, maka bilangan tersebut genap.
